# Disciple.Tools - User Management (Deprecated)

> **This plugin is deprecated and no longer maintained.** Its users table is part of the Disciple.Tools theme as of version 1.47.0. Deactivate and delete this plugin.

The theme's **Users** page (top navigation › Users, at `/user-management/users/`) has the users table this plugin provided. It handles thousands of users, with search, sorting and per-column filters.

The final release of this plugin loads nothing, so it won't conflict with the theme if it's still installed.
